# Create a rewards calendar

1. Open **Daily Rewards → Create calendar**.
2. Select the **server, year and month** and create the calendar.
3. Select a day in the calendar grid.
4. Enable the day and add **item IDs** with **quantities**.
5. Click **Apply**, then **Save calendar**.
6. Enable the calendar once configured.

You can copy the previous day's rewards or fill empty days.

::: warning
New calendars are **disabled** by default. **Apply** does not save the whole month; you must select **Save calendar**.
:::
