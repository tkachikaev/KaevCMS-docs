# Daily Rewards

**Daily Rewards** provides monthly reward calendars for game servers. Administrators assign items to specific days; players collect them in **Web Inventory**.

Each day's gift can only be claimed on its scheduled date, once per eligible game account. Missed days expire.

## Getting started

1. Enable **Daily Rewards** under **Modules**.
2. Open **Daily Rewards** in administration.
3. Create a calendar and configure gifts.
