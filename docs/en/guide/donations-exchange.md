# Donations → Coin exchange

Players can exchange KaevCMS wallet coins for game items. Each GameServer has its own settings.

1. Open **Donations → Transfer coins to game**.
2. Set the **item ID** and the number of items **per 1 CMS coin** for the chosen server.
3. Enable exchange and save.

For example, a rate of `10` gives ten game items for one CMS coin.

::: warning
Items first arrive in **Web Inventory**, not directly on the character. [Transferring them to the GameServer queue](/en/guide/reward-delivery) is a separate step.
:::
