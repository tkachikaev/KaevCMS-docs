# Donations → Providers

A **provider** accepts a player's coin purchase. KaevCMS credits the player's wallet only after verifying the payment.

## Connect a provider

1. Open **Donations → Payment systems** in administration.
2. Choose the provider and click **Configure**.
3. Enter the account details and configure notifications.

## Provider instructions

- **[YooMoney — payment setup](/en/guide/donations-yoomoney)**

KaevCMS displays the YooMoney notification URL automatically. Copy it to YooMoney settings; no custom code is necessary.
