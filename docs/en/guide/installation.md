# Installing KaevCMS

Choose how your website will be hosted:

- **[Ubuntu / VPS](/en/guide/vds)** — a server you administer.
- **[Shared hosting](/en/guide/shared-hosting)** — a conventional hosting provider.

After installation, follow the [quick start](/en/guide/getting-started) and [game-server guide](/en/guide/game-servers). To upgrade an existing site, use the [updates guide](/en/guide/updates).
