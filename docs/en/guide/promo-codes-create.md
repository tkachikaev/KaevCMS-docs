# Create a promo code

1. Open **Promo Codes → Create promo code**.
2. Enter a code and select the **game server**.
3. Add rewards using each **item ID** and **quantity**.
4. Optionally specify validity dates and redemption limits.
5. Save the code and make sure it is enabled.

Players redeem the code in their account; successful redemption grants items to Web Inventory.

::: tip
Test a new code with a test account before distributing it.
:::
