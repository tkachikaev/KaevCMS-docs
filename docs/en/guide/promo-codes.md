# Promo Codes

**Promo Codes** distributes rewards using a redeemable code. Administrators create a code for a game server; players redeem it in their account and receive items in **Web Inventory**.

## Getting started

1. Enable **Promo Codes** under **Modules**.
2. Open **Promo Codes** in administration.
3. Create a code and select the server and rewards.

**[Create a promo code →](/en/guide/promo-codes-create)**

Usage statistics and redemption history are available in administration. To deliver items to characters, use the [reward queue](/en/guide/reward-delivery).
