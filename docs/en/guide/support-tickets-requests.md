# Managing tickets

Players create requests under **Account → Support Tickets**.

## Reply to a ticket

1. Open **Support Tickets → Tickets** in administration.
2. Choose a ticket and read the conversation.
3. Optionally **assign a staff member**.
4. Send a reply or add an **internal note** hidden from players.
5. Update the status or close the ticket.

Editor permissions for replies and notes are configured separately. Auditors have read-only access.
