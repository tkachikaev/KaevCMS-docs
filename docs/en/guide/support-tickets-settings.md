# Support settings

Open **Support Tickets → Settings** in administration.

## General settings

The site owner can:

- Allow editors to view tickets, send replies and create **internal notes**.
- Configure limits for open tickets and messages.
- Choose a **retention period for closed tickets**.

Save after making changes.

## Database cleanup

The **Database cleanup** tab lets you preview removal of old history and run cleanup. Open and retention-protected tickets are preserved.
