# Sources and support

## Official resources

- **[KaevCMS source](https://github.com/tkachikaev/KaevCMS)**: application, CHANGELOG and source documentation.
- **[Releases](https://github.com/tkachikaev/KaevCMS/releases)**: installation packages, release notes and available checksums.
- **[Issues](https://github.com/tkachikaev/KaevCMS/issues)**: bug reports and support questions.
- **[English technical documentation](https://github.com/tkachikaev/KaevCMS/tree/main/docs/en)**: detailed operational procedures.
- **[Documentation website repository](https://github.com/tkachikaev/KaevCMS-docs)**: this site's source, translations and styling.

## Useful issue reports include

1. KaevCMS version and installation or update package.
2. Environment: VPS or shared hosting, PHP and database versions.
3. Exact reproduction steps.
4. Expected and actual behavior.
5. Redacted error text without passwords, tokens or private infrastructure details.

::: info Documentation baseline
This website was initially prepared from the published KaevCMS repository, which contained version **0.47.38** at the time. Later features may only be present in newer releases, while older source documents may describe earlier versions. Always compare these instructions with your installed release.
:::
