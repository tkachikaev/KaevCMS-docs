## What is KaevCMS?

KaevCMS is a free and open-source Laravel application for Lineage II server websites. Features depend on the installed version, integration driver and game-server database schema.

**Important:** this documentation is based on the published repository. Always check [GitHub Releases](https://github.com/tkachikaev/KaevCMS/releases) before deploying or upgrading.
