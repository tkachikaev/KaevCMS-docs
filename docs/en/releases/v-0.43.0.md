# KaevCMS 0.43.0

**Published:** 2026-07-28 · **Type:** Pre-release

[Original release on GitHub ↗](https://github.com/tkachikaev/KaevCMS/releases/tag/0.43.0)

## What's new

## KaevCMS 0.43.0 — First Public Release

KaevCMS is an open-source Laravel-based CMS for Lineage II servers.

It includes a public website, player account panel, administration panel, LoginServer and GameServer integration, server statistics, web inventory rewards, promo codes, daily rewards, themes, localization, and an update system.

### What Changed in 0.43.0

Version 0.43.0 establishes a new public release line for KaevCMS.

* Removed outdated pre-release documentation.
* Cleaned up the production package.
* Removed old audit files.
* Set version 0.42.4 as the new cumulative update baseline.
* Fixed a Windows regression in the cumulative update workflow tests.
* Added deletion contracts for obsolete files during updates.

The CMS database schema, game drivers, bundled modules, themes, and user runtime files were not changed.

### Which Archive Should I Download?

#### `KaevCMS-0.43.0-full.zip`

The standard full package.

Use this package for:

* a VDS or dedicated server;
* local installation;
* hosting where the document root can be pointed to the `public` directory;
* development or custom project builds.

This archive does not include a ready-to-use `vendor` directory. PHP dependencies must be installed through Composer.

#### `KaevCMS-0.43.0-shared-hosting.zip`

A ready-to-use production package for shared hosting.

Use this package when your hosting provider does not allow the domain document root to point directly to the `public` directory.

The package is already split into:

* the private application core in `kaevcms-core`;
* the public directory in `public_html`;
* production Composer dependencies without development packages.

The directories may be renamed to match the structure required by your hosting provider. For example, the public directory may use the domain name instead of `public_html`.

### Requirements

* PHP 8.3 or newer;
* MySQL or MariaDB;
* PDO and `pdo_mysql`;
* mbstring;
* fileinfo;
* DOM;
* OpenSSL;
* tokenizer;
* ctype;
* JSON;
* session;
* HTTPS for production use.

### Installation

1. Extract the appropriate archive.
2. Point the domain to the public directory.
3. Open the following address in your browser:

```text
https://your-domain.com/install/
```

4. Complete the Web Installer steps.
5. After installation is complete, remove the public `/install` directory.

Do not place `.env`, application source code, logs, backups, or the private application core inside a publicly accessible directory.

Do not assign `777` permissions to the entire project.

### Main Features

* public website and player account panel;
* administration panel;
* Russian and English localization;
* owner, administrator, and editor roles;
* two-factor authentication;
* LoginServer and GameServer connections;
* L2JMobius support through database schema profiles;
* external database connection and schema diagnostics;
* game account creation;
* game account password changes;
* character, clan, hero, and castle statistics;
* web inventory rewards;
* universal `kaev_reward_queue`;
* bundled Promo Codes and Daily Rewards modules;
* public website themes and separate account panel themes;
* game item catalog and custom item icons;
* Web Updater for shared hosting;
* CLI Updater for VDS installations;
* backups and recovery during updates.

### Updating

To update KaevCMS 0.42.4 to version 0.43.0, use:

```text
KaevCMS-cumulative-update-0.42.4-to-0.43.0.zip
```

On shared hosting, upload the package through the Web Updater in the administration panel.

Files stored in `public/uploads`, `.env` settings, the active CMS database, logs, and other runtime data are not replaced during the update.
