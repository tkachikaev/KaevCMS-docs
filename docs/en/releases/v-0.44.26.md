# KaevCMS 0.44.26

**Published:** 2026-07-30 · **Type:** Pre-release

[Original release on GitHub ↗](https://github.com/tkachikaev/KaevCMS/releases/tag/0.44.26)

## What's new

## Changes introduced between versions 0.43.0 and 0.44.26

- Added full support for different L2JMobius builds through a unified driver.
- Added the new **Support Tickets** module with conversations, statuses, categories, internal notes, assigned staff and automatic cleanup.
- Replaced the old news and page editor with **Tiptap**, including tables, images, links, lists, alignment, text sizes and an expanded color palette.
- Improved the administration panel, player account area, filters, responsive layouts and module icons.
- Improved security, Livewire authorization, installation, update workflows and automated testing.
- Fixed a file-cache issue that could occasionally cause an HTTP 500 error.
- Fixed multiple bugs and improved overall stability.

### Full VDS package

`KaevCMS-0.44.26-full.zip`

Use this package for a clean KaevCMS installation on a VDS.

### Shared hosting package

`KaevCMS-0.44.26-shared-hosting.zip`

Use this package for a clean KaevCMS installation on shared hosting.

### Cumulative update to 0.44.26

For installations running versions from **0.42.4** through **0.44.25**:

`KaevCMS-cumulative-update-0.42.4-0.44.25-to-0.44.26.zip`

- VDS installations must apply the cumulative update from the server console.
- Shared hosting installations can apply the cumulative update through the update section in the administration panel settings.
