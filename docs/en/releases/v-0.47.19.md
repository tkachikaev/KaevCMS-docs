# KaevCMS 0.47.19

**Published:** 2026-08-02 · **Type:** Pre-release

[Original release on GitHub ↗](https://github.com/tkachikaev/KaevCMS/releases/tag/0.47.19)

## What's new

## Added

- CMS updates through the admin panel on VDS.
- Secure local VDS update agent without open network ports.
- Support for projects owned by root or a regular system user.
- Update progress window with automatic status tracking.
- Administrator notification center.
- Configurable notification sources and retention period.
- Safe diagnostic package for support requests.
- New dashboard statistics for storage, database, players, accounts, characters and support tickets.
- Promo code archive with restoration support.
- Permanent deletion of unused promo codes.
- Deletion of closed support tickets by the project owner.
- Shared admin components for fields, buttons, tabs, filters and cards.

## Changed

- Improved System Information page.
- Improved system update interface and update logs.
- Improved mobile admin and account navigation.
- Added protection against repeated update submissions.
- Technical Web Inventory messages were replaced with clear player-facing messages.
- Reward delivery status is now displayed as “Delivered”.
- Support Tickets fields and filters now follow the common admin design.
- Improved permissions for Owner, Administrator, Editor and Auditor.
- The installer is removed automatically after a successful installation.

## Fixed

- False `429 Too Many Requests` errors during CMS updates.
- False 429 errors when testing asynchronous mail mode.
- File permission issues after VDS updates.
- Update issues on root-owned VDS installations.
- Occasional HTTP 500 errors after Web Update.
- VDS update agent compatibility with different PHP-FPM configurations.
- Internal database and field names being displayed to players.
- Web Inventory character and reward validation.
- Repeated notifications and diagnostic messages.
- Mobile layout overflow and horizontal scrolling.
- Module update and migration reliability.
- Release package, metadata and automated test stability.

## Included components

- Promo Codes 1.4.0
- Daily Rewards 1.3.1
- Support Tickets 1.7.1
- L2 Dark Classic 0.8.2
- Kaev Aurelia 1.0.9
- Kaev Aurelia Account 1.6.5
- L2 Obsidian Luxury 1.6.4

The cumulative update package supports direct updates from KaevCMS 0.42.4–0.47.18 to 0.47.19.
