# Создание календаря наград

1. Откройте **Ежедневные награды → Создать календарь**.
2. Выберите **сервер, год и месяц**, затем создайте календарь.
3. Нажмите нужный день в сетке.
4. Включите этот день и добавьте предметы: **ID** и **количество**.
5. Нажмите **«Применить»**, затем **«Сохранить календарь»**.
6. После настройки всех дней включите календарь для игроков.

Можно копировать награды предыдущего дня и заполнять пустые дни.

::: warning
Новый календарь создаётся **выключенным**. Нажатие «Применить» само по себе не сохраняет весь месяц: нужно нажать **«Сохранить календарь»**.
:::
