# Ежедневные награды

**Daily Rewards** — месячные календари подарков для игровых серверов. Администратор задаёт награды по дням; игрок получает их **в Веб-инвентарь**.

Награда конкретного дня доступна только в соответствующую дату. Один игровой аккаунт может забрать её один раз; пропущенные дни не переносятся.

## Начало работы

1. Включите **Daily Rewards** в разделе **«Модули»**.
2. Откройте **«Ежедневные награды»** в админке.
3. Создайте календарь и настройте подарки.
