# Donations → Перевод монет в игру

Игрок может обменять монеты кошелька KaevCMS на игровые предметы. Настройка выполняется отдельно для каждого GameServer.

1. Откройте **Пожертвования → Перевод монет в игру**.
2. Для нужного сервера задайте **ID предмета** и количество предметов **за 1 монету CMS**.
3. Включите обмен и сохраните настройки.

Например, при курсе `10` одна монета CMS обменивается на десять игровых предметов.

::: warning
После обмена предметы попадают **в Веб-инвентарь**, а не непосредственно персонажу. Дальнейшая [передача в игровую базу](/guide/reward-delivery) выполняется отдельно.
:::
