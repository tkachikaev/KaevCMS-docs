# Подключение FreeKassa

FreeKassa позволяет игрокам пополнять кошелёк KaevCMS через платёжную страницу сервиса.

::: warning Статус интеграции
В новых сборках KaevCMS FreeKassa помечена как **«Альфа»**: полная проверка реальных платежей ещё не завершена. Если провайдера нет в вашей админке, проверьте версию CMS. Перед открытием оплаты игрокам проведите контрольный платёж.
:::

## 1. Настройте магазин FreeKassa

1. Создайте магазин на [официальном сайте FreeKassa](https://freekassa.net/) и откройте [настройки магазина](https://merchant.freekassa.net/settings). Магазину может потребоваться модерация.
2. В админке KaevCMS откройте **Пожертвования → Платёжные системы → FreeKassa**.
3. Скопируйте **«Адрес уведомлений»** из KaevCMS (кнопка **«Копировать»**) в поле **«URL оповещения»** магазина. Выберите метод **POST**.
4. Перенесите из FreeKassa в KaevCMS **ID магазина**, **Секретное слово 1** и **Секретное слово 2**. Для настоящих платежей дополнительно понадобится **API-ключ FreeKassa** — он находится в настройках мерчанта.
5. Выберите валюты, для которых уже настроена цена монеты в **Пожертвования → Валюты и цены**, и сохраните настройки.

::: tip
Раздел **«Безопасность уведомлений FreeKassa»** уже содержит первоначальный список доверенных IP. Сверяйте его с [официальной документацией FreeKassa](https://docs.freekassa.net/). Если сайт работает за Cloudflare или обратным прокси, проверьте дополнительные настройки в этом разделе. Без корректного списка IP уведомления не пройдут.
:::

## 2. Проверьте кнопкой «Тест»

1. **Сначала включите тестовый режим в кабинете FreeKassa.** KaevCMS не переключает его за вас. Если оставить реальный режим у мерчанта, деньги могут списаться по-настоящему.
2. В блоке **«Приём платежей»** выберите **«Тестовый режим»**, отметьте хотя бы одну валюту и сохраните. Включать приём платежей для теста **не нужно**.
3. Нажмите **«Тест»** рядом с адресом уведомлений. В открывшемся окне выберите валюту и сумму, затем нажмите **«Открыть тестовую оплату»**. Если валюта не выбрана, окно подскажет об этом вместо пустого списка.
4. Завершите тест на странице FreeKassa, она откроется в новой вкладке, и вернитесь на вкладку KaevCMS.

Пока CMS ждёт подписанное уведомление, в окне крутится индикатор, затем появляется зелёная галочка (**«Тестовая оплата подтверждена»**) или красный крестик. Результат хранится на сервере и остаётся до следующего теста: окно можно закрыть и вернуться позже. На ожидание отводится до **30 минут**. **Монеты за такой тест не начисляются**, а FreeKassa в тестовом режиме игрокам не показывается.

## 3. Включите настоящие платежи

После проверки отключите тестовый режим **в кабинете FreeKassa**, укажите API-ключ, выберите в KaevCMS **«Боевой режим»**, включите **«Принимать платежи через FreeKassa»** и сохраните.

Этот переключатель единственный: когда сайт готов, KaevCMS сам открывает оплату игрокам. Если не готов, страница покажет, чего не хватает: публичного HTTPS, рабочего режима, подходящей базы данных или цены монеты для выбранной валюты. Выключение FreeKassa останавливает только её, остальные провайдеры продолжают работать.

Начните с небольшого **реального контрольного платежа**. Монеты начисляются только после проверки платежа через уведомление и API FreeKassa, а не просто после возвращения игрока на сайт.

## Если не работает

- **Тест не подтверждён:** проверьте HTTPS, URL оповещения, метод POST, секрет 2 и доверенные IP.
- **Нет оплаты у игроков:** проверьте боевой режим, API-ключ, включён ли **«Принимать платежи через FreeKassa»**, HTTPS, рабочий режим и цену валюты.
- **Заказ оплачен, монет нет:** найдите заказ в админке и используйте проверку через FreeKassa API, если она доступна. Не начисляйте монеты только по скриншоту.
