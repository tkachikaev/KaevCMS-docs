# Подключение PayPal

PayPal позволяет игрокам оплачивать монеты KaevCMS через **ваш собственный PayPal Business-аккаунт**. Деньги поступают владельцу аккаунта PayPal, монеты — в кошелёк игрока.

::: warning Статус интеграции
В новых сборках KaevCMS PayPal помечен как **«Альфа»**: полный боевой контроль ещё не завершён. Если PayPal нет в вашей версии CMS, сначала проверьте доступность обновления. Не включайте Live для игроков без собственной проверки Sandbox и небольшого реального платежа.
:::

## 1. Получите реквизиты PayPal

1. Откройте [PayPal Developer Dashboard](https://developer.paypal.com/dashboard/applications/) и войдите под аккаунтом, связанным с **PayPal Business**.
2. В разделе приложений PayPal выберите **Live** и создайте (или откройте) REST-приложение. Скопируйте **Client ID** и **Client Secret**.
3. Найдите **Merchant ID (PayPal account ID)** вашего Business-аккаунта. Это **не** Client ID приложения.
4. В KaevCMS откройте **Пожертвования → Платёжные системы → PayPal** и заполните реквизиты **Live** в блоке **«Данные подключения»** (Client ID, Client Secret, Webhook ID и Merchant ID). Тестовые реквизиты Sandbox вводятся отдельно, в окне **«Тест»**.
5. Выберите валюты, для которых задана цена монеты в **Пожертвования → Валюты и цены**, затем сохраните настройки.

Секреты хранятся в зашифрованном виде. Если поле уже сохранённого секрета оставить пустым, старое значение сохранится.

## 2. Настройте уведомления (webhook)

1. Скопируйте **адрес уведомлений PayPal** из админки KaevCMS.
2. Откройте своё приложение в [PayPal Developer Dashboard](https://developer.paypal.com/dashboard/applications/) и добавьте **Webhook URL**. Выберите события, перечисленные в раскрывающейся **«Инструкции по подключению»** на странице PayPal в KaevCMS.
3. После создания webhook скопируйте выданный **Webhook ID** в соответствующее поле KaevCMS и сохраните.

**Не путайте:** **Webhook URL** — адрес вашего сайта, **Webhook ID** — идентификатор, который выдаёт PayPal. Для Sandbox и Live создаются отдельные настройки, хотя URL в KaevCMS может быть одинаковым.

[Официальная инструкция PayPal по webhook](https://developer.paypal.com/api/rest/webhooks/rest/).

## 3. Проверьте кнопкой «Тест»

1. В PayPal Developer Dashboard подготовьте **Sandbox-приложение** и тестовые аккаунты **Business** (продавец) и **Personal** (покупатель). [Как устроен Sandbox](https://developer.paypal.com/sandbox-testing/overview/).
2. Рядом с адресом уведомлений в KaevCMS нажмите **«Тест»**. В появившемся окне откройте **«Тестовые реквизиты (Sandbox)»**, введите Sandbox Client ID, Client Secret и Webhook ID, затем сохраните.
3. В списке проверки выберите **«Тестовые реквизиты (Sandbox)»** и нажмите **«Проверить реквизиты»**. Это проверяет доступ к PayPal API, но ещё не саму оплату. Этим же списком можно проверить **«Боевые реквизиты (Live)»**.
4. Убедитесь, что на странице настроек отмечена валюта: если нет, окно попросит её выбрать. Затем выберите валюту и сумму, нажмите **«Открыть PayPal Sandbox»** и подтвердите оплату тестовым аккаунтом **покупателя**.
5. После возврата, если отображается статус **APPROVED**, нажмите **«Подтвердить Sandbox Capture»**.

Блок результата в окне крутится, пока CMS ждёт ответ, затем показывает зелёную галочку (**«Тест пройден: PayPal подтвердил платёж»**) или красный крестик. Результат хранится на сервере до следующего теста.

**Это тест без настоящих денег и без начисления монет.** Подтверждение покупки в браузере само по себе не означает, что Capture завершён.

## 4. Включите Live

Проверьте реквизиты и webhook **Live** отдельно от Sandbox. После контрольного реального платежа включите **«Принимать платежи через PayPal»** и сохраните. Когда сайт готов, KaevCMS сам открывает оплату игрокам; если нет, страница перечислит, чего не хватает (HTTPS, рабочий режим, подходящая база данных, цена монеты для валюты). Выключение PayPal не влияет на других провайдеров.

Если платёж завис, найдите заказ в админке и используйте **«Проверить через PayPal API»**. Проверка не инициирует повторное списание. Уведомления о возвратах и спорах показываются администратору, но монеты автоматически не списываются.

::: tip
Работа PayPal Business, доступность валют и допустимость платежей за игровые монеты зависят от страны и правил PayPal. Проверьте ограничения своего аккаунта до запуска.
:::
