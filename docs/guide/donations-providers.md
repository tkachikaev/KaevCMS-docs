# Пожертвования → Провайдеры

**Провайдер** — платёжный сервис, через который игрок оплачивает монеты KaevCMS. После подтверждения платежа монеты поступают на кошелёк игрока.

## Как добавить

1. Откройте в админке **Пожертвования → Платёжные системы**.
2. Выберите провайдера и нажмите **«Настроить»**.
3. Укажите реквизиты и настройте уведомления по инструкции провайдера.

## Инструкции

- **[ЮMoney — подключение и проверка кнопкой «Тест»](/guide/donations-yoomoney)**

Для ЮMoney адрес уведомлений KaevCMS создаёт автоматически. После получения тестового уведомления с правильной подписью CMS сохраняет настройки сама.

[Вернуться к «Пожертвованиям»](/guide/donations).
