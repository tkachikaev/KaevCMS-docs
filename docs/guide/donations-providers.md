# Пожертвования → Провайдеры

**Провайдер** — платёжный сервис, через который игрок оплачивает монеты KaevCMS. После подтверждения платежа монеты поступают на кошелёк игрока.

## Как добавить

1. Откройте в админке **Пожертвования → Платёжные системы**.
2. Выберите нужного провайдера и нажмите **«Настроить»**.
3. Заполните реквизиты и настройте уведомления по инструкции провайдера.

## Доступные инструкции

- **[ЮMoney — подключение оплаты](/guide/donations-yoomoney)**

Адрес для уведомлений ЮMoney KaevCMS показывает автоматически. Его нужно перенести в настройки ЮMoney; дописывать код не требуется.

[Вернуться к Пожертвования](/guide/donations).
