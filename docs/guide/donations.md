# Пожертвования

**Пожертвования** — модуль пополнения кошелька игрока. Игрок оплачивает монеты через подключённую платёжную систему, а после подтверждения платежа KaevCMS начисляет их на баланс.

Также модуль позволяет обменивать монеты CMS на игровые предметы через **Веб-инвентарь**.

## С чего начать

1. Включите модуль **Пожертвования** в административной панели KaevCMS.
2. Откройте его вкладку **«Настройки»** и задайте стоимость монеты в разделе **«Валюты и цены»**.
3. Подключите платёжную систему в разделе **«Платёжные системы»**.
4. После настройки проверьте оплату на небольшую сумму.

## [Провайдеры](/guide/donations-providers)

Провайдер — сервис, который принимает оплату от игрока и отправляет KaevCMS уведомление о переводе.

### ЮMoney

Сейчас для приёма платежей предусмотрена интеграция с **ЮMoney**: администратор указывает кошелёк, переносит адрес уведомлений из CMS в ЮMoney и включает приём платежей.

**[Инструкция: ЮMoney →](/guide/donations-yoomoney)**

## [Перевод монет в игру](/guide/donations-exchange)

На вкладке **«Перевод монет в игру»** можно установить для каждого GameServer игровой предмет и количество предметов за одну монету CMS.

При обмене предметы попадают сначала в **Веб-инвентарь**. Дальше игрок может передать их персонажу через [очередь наград](/guide/reward-delivery).
