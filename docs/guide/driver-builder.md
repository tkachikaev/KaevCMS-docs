# Конструктор драйверов (бета)

**Для подключения новой Java-сборки больше не обязательно просить разработчика KaevCMS написать отдельный драйвер.** Теперь администратор может сам описать структуру игровой базы через визуальный конструктор — без программирования.

Драйвер объясняет CMS, где игровая сборка хранит **аккаунты, персонажей, статистику и другие данные**. Настройки можно сохранить в JSON и передать владельцам такой же сборки.

::: warning Бета
Конструктор появился в KaevCMS **0.54.x** и ещё проходит проверку на реальных сборках. Это не обещание полной совместимости **со всеми** Java-серверами: сейчас поддерживаются **MySQL/MariaDB** и только операции, предусмотренные движком. **MS SQL / PTS пока не поддерживаются.** Начинайте с тестовой базы.
:::

## Что умеет конструктор

| Тип драйвера | Что настраивается |
| --- | --- |
| **LoginServer** | Игровые аккаунты, поля логина и пароля, создание аккаунтов, смена пароля, доступные дополнительные поля. |
| **GameServer** | Список персонажей, классы и уровни, онлайн, PvP/PK, рейтинги, герои, замки, связи между таблицами и фильтры. |
| **JSON-профиль** | Сохранение, копирование, экспорт и импорт настроек совместимости. |

Можно взять готовый профиль **L2J Mobius** или **RUSaCis** за основу и изменить его под свою базу.

## Создаём свой драйвер

1. Откройте **Админка → Серверы → Драйверы**.
2. Выберите вкладку **LoginServer** или **GameServer** и нажмите **«Создать драйвер»**.
3. Если таблицы похожи на известную сборку, используйте **«Создать на основе существующего»**. Иначе начинайте с пустого профиля.
4. Укажите название, нужные функции и кодировку базы.
5. В следующих разделах редактора сопоставьте поля CMS с **реальными таблицами и столбцами** игровой БД. Например, укажите, где хранится имя персонажа.
6. Для LoginServer выберите **поддерживаемый формат игрового пароля**; для GameServer при необходимости настройте рейтинги, фильтры, героев и замки.
7. Нажмите **«Сохранить драйвер»**.

Создание профиля **не меняет игровую базу** и **не переключает существующие подключения**.

## Подключаем драйвер к серверу

1. Откройте настройки нужного **LoginServer** или **GameServer** в разделе «Серверы».
2. Выберите новый драйвер, сохраните настройки подключения.
3. В списке серверов нажмите **«Применить JSON и проверить»**.
4. CMS проверит соединение, обязательные таблицы, столбцы и связи. Если есть ошибки, исправьте профиль и повторите проверку.
5. После успеха проверьте на тестовом аккаунте регистрацию, вход в игру, персонажей и нужные функции.

::: info
**Проверка схемы не равна проверке всей игры.** Даже если CMS нашла таблицы и столбцы, выбранный формат пароля может не подойти вашей сборке. Проверяйте реальный вход игровым клиентом. После изменения драйвера или параметров подключения снова выполните **«Применить JSON и проверить»**.
:::

## Поделиться драйвером

Готовый профиль можно **экспортировать в JSON**, отправить другому администратору, а он импортирует файл в свою CMS. В экспорт не включаются **адреса БД, логины и пароли подключения**.

**[Как импортировать и экспортировать JSON-драйвер →](/guide/driver-json)**

## Ограничения бета-версии

- Пока **только MySQL/MariaDB**, без MS SQL/PTS.
- Алгоритмы игровых паролей — из готового списка (например, SHA-1/Base64, BCrypt `$2a$`, SHA/MD5/Whirlpool в hex), **не произвольный код**.
- Нестандартные способы хранения данных и отдельные операции могут потребовать доработки движка.
- Конструктор не заменяет [очередь наград](/guide/reward-delivery) для фактической выдачи предметов в игре.

**Итог:** теперь владельцы многих Java-сборок могут адаптировать KaevCMS самостоятельно. Работоспособность следует подтверждать для каждой конкретной схемы и функции.
