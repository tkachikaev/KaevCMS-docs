# Импорт и экспорт JSON-драйверов

**Конструктор драйверов — бета.** Если вы настроили профиль под свою сборку, его можно экспортировать и передать другому администратору. Ему не придётся заполнять те же поля заново.

## Экспорт

1. Откройте **Админка → Серверы → Драйверы**.
2. Выберите **LoginServer** или **GameServer** и найдите профиль.
3. Нажмите **«⋯» → «Экспортировать»**.
4. Сохраните скачанный файл `kaevcms-login-имя.json` или `kaevcms-game-имя.json`.

Файл описывает **таблицы, колонки и функции**, но **не содержит адреса, логина и пароля игровой БД**. Перед публикацией всё равно просмотрите содержимое.

## Импорт

1. Откройте **Серверы → Драйверы → Импортировать**.
2. Выберите файл **`.json` не больше 256 КБ** и подтвердите импорт.
3. Профиль появится во вкладке своего типа сервера. При необходимости измените названия таблиц и колонок.
4. При настройке своего **LoginServer** или **GameServer** выберите импортированный драйвер в списке.

Если ID уже занят, CMS создаёт **отдельную копию с новым ID**, не затирая существующий профиль.

::: warning
Импорт **не переключает существующие серверы**. Совместимость и доступные функции зависят от структуры игровой базы. Для LoginServer и GameServer используются **отдельные профили**.
:::
