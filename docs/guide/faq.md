# Частые вопросы

## KaevCMS бесплатная?

Да. Исходный код опубликован с лицензией MIT. Ознакомьтесь с [лицензией в репозитории](https://github.com/tkachikaev/KaevCMS/blob/main/LICENSE).

## Где скачать установщик?

На странице [официальных релизов](https://github.com/tkachikaev/KaevCMS/releases). Проверьте, что скачиваете полный пакет для вашей среды.

## Можно установить на обычный хостинг?

Да, при соответствии требованиям PHP/MySQL и поддержке нужной файловой структуры. Для хостингов без настраиваемого Document Root предусмотрен отдельный split-пакет. [Инструкция](/guide/shared-hosting).

## Какие хроники поддерживаются?

Это зависит от используемого драйвера и конкретной схемы LoginServer/GameServer. Ориентируйтесь на [документацию интеграции](/guide/game-servers), а не только на название хроник.

## Нужно ли устанавливать Java или GameServer на том же хосте?

Нет. CMS подключается к базам игрового сервера отдельно. Java-компоненты, если нужны для каких-либо игровых интеграций, управляются владельцем GameServer независимо от CMS.

## Можно обновляться без переустановки?

Да, но только подходящим пакетом обновления из заявленного диапазона версий. [Процедура обновления](/guide/updates).

## Есть ли поддержка платежей?

Функции платежей могут находиться в разработке. **Не считайте конкретный платёжный провайдер доступным**, пока его безопасный производственный сценарий не заявлен и не проверен в опубликованном релизе.

## Где задать вопрос или сообщить об ошибке?

Используйте [GitHub Issues](https://github.com/tkachikaev/KaevCMS/issues) и не прикладывайте секреты или закрытые дампы баз.
