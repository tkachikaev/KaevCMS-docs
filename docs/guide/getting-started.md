# Быстрый старт

## 1. Подготовьте окружение

Для обычной установки KaevCMS требуются:

- PHP **8.3 или новее**;
- MySQL либо MariaDB и отдельная пустая база;
- необходимые расширения PHP: PDO, pdo_mysql, mbstring, fileinfo, DOM, OpenSSL, tokenizer, ctype, JSON и session;
- работающий HTTPS для публичного проекта;
- каталоги с корректными правами записи: storage, bootstrap/cache, public/uploads.

Для подготовки проекта используется Composer. На обычном хостинге можно воспользоваться подготовленным split-пакетом.

## 2. Скачайте правильный архив

Откройте [официальные релизы](https://github.com/tkachikaev/KaevCMS/releases). Для чистой установки выбирайте **полный релиз**, предназначенный для вашего типа размещения. Архив обновления не заменяет полный установочный пакет.

Перед развёртыванием проверьте опубликованную SHA-256, если она предоставлена.

## 3. Выберите инструкцию

- [Ubuntu / VDS](/guide/vds) — когда у вас есть SSH, nginx и возможность задать Document Root.
- [Виртуальный хостинг](/guide/shared-hosting) — когда публичный каталог имеет фиксированное имя, например public_html.

## 4. Завершите установку

Web Installer доступен по пути:

~~~text
https://example.com/install/
~~~

Мастер проверяет окружение, соединение с пустой базой и создаёт владельца CMS. После успешной установки публичная папка install должна быть удалена; проверьте это самостоятельно.

## 5. Проверьте работу

1. Войдите в административную панель под владельцем.
2. Настройте [LoginServer и GameServer](/guide/game-servers).
3. Укажите SMTP и отправьте тестовое письмо.
4. Проверьте scheduler, очереди и системную диагностику.
5. Убедитесь, что APP_DEBUG выключен, а доступ через HTTPS работает.

::: warning Важное правило
Веб-сервер должен отдавать **только публичный каталог**. Никогда не публикуйте .env, vendor, исходники, журналы и бэкапы.
:::
