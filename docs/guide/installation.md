# Установка KaevCMS

Выберите свой вариант размещения сайта:

- **[Ubuntu / VDS](/guide/vds)** — собственный сервер с доступом к настройкам ОС.
- **[Виртуальный хостинг](/guide/shared-hosting)** — обычный хостинг с панелью управления.

После установки переходите к [быстрому старту](/guide/getting-started) и [игровым серверам](/guide/game-servers). Для уже работающего сайта используйте [инструкцию по обновлению](/guide/updates).
