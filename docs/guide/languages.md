# Языки KaevCMS

В KaevCMS по умолчанию установлены **русский и английский языки**. Администратор может включать и выключать доступные языки, выбирать основной язык сайта и добавлять собственные переводы.

Язык интерфейса можно переключать на сайте, в личном кабинете игрока и в административной панели. В список попадают только **включённые** языки.

## Настройка языков

Откройте **Админка → Настройки → Языки**.

На странице есть три основные настройки:

| Параметр | Назначение |
| --- | --- |
| **Установленные языки** | Список обнаруженных пакетов. Отметьте языки, которые должны быть доступны пользователям. |
| **Язык по умолчанию** | Язык для нового посетителя, если он ещё не выбрал другой. |
| **Резервный язык** | Используется, если для выбранного языка отсутствует перевод. |

Нажмите **«Сохранить настройки языков»**. Основной и резервный языки должны быть **включены**, а хотя бы один язык всегда должен оставаться активным.

Система запоминает выбор пользователя; у администратора переключение языка интерфейса работает отдельно от выбора языка посетителем.

## Как добавить ещё один язык

Новые языковые пакеты **не требуют изменения исходного кода CMS или базы данных**. Для начала нужно добавить в папку `lang` два файла: описание языка и переводы. После этого язык появится в админке, где его можно включить.

**[Пошаговая инструкция: создаём свой языковой пакет →](/guide/language-pack)**

::: info
Сейчас админка **обнаруживает и включает установленные пакеты**, но не загружает языковые файлы сама. Новый пакет помещается на сервер через файловый менеджер хостинга, SFTP или другой штатный способ работы с файлами.
:::

## Что переводится автоматически

| Раздел | Как работает перевод |
| --- | --- |
| **Кнопки, меню и подписи CMS** | Переводы читаются из файлов языкового пакета. |
| **Личный кабинет и админка** | Используют выбранный язык; недостающие фразы могут показываться на резервном языке. |
| **Новости и обычные страницы** | Тексты на нужном языке создаются отдельно в редакторе контента. |
| **Название сайта и другие локализуемые настройки** | Для каждого языка значения можно задать отдельно через настройки. |
| **Письма** | Шаблоны для нового языка можно отредактировать на вкладках почты. |
| **Модули** | Некоторые строки хранятся в собственных файлах переводов модулей — отдельная часть локализации. |

**Процент перевода** в списке языков рассчитывается по ключам основного JSON-файла относительно английского. Он не измеряет перевод новостей, модулей, почтовых шаблонов и всех дополнительных PHP-файлов.
