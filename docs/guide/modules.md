# Модули KaevCMS

Модули добавляют новые возможности для сайта и личного кабинета. Здесь представлены **четыре встроенных модуля KaevCMS**. Все они доступны бесплатно и находятся в официальном репозитории.

<ModuleCatalog lang="ru" />

## Как включить модуль?

1. Войдите в панель администратора под владельцем сайта.
2. Откройте раздел **«Модули»**.
3. Выберите нужный модуль, включите его и откройте настройки.
4. Для наград и промокодов настройте игровой сервер и веб-инвентарь. Чтобы предметы действительно попадали персонажам, следуйте инструкции **[Передача предметов в игру](/guide/reward-delivery)**.

::: info Что значит «Бесплатно»
За перечисленные модули не требуется отдельная лицензия. Комиссии внешних платёжных сервисов (например, ЮMoney) могут взиматься отдельно. Предоставление награды из веб-инвентаря персонажу в игре зависит от настроенной игровой интеграции.
:::
