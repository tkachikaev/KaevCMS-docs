# Что такое KaevCMS

KaevCMS — CMS с открытым исходным кодом для сайтов Lineage II серверов. Основное приложение использует **Laravel**, **PHP 8.3+**, **MySQL/MariaDB** и Livewire.

## Основные возможности

| Область | Что входит |
| --- | --- |
| Публичный сайт | Новости, страницы, темы оформления, многоязычный контент и навигация |
| Кабинет игрока | Учётная запись сайта, игровые аккаунты, персонажи, аватары и веб-инвентарь |
| Интеграции | Отдельные подключения к LoginServer и GameServer через драйверы |
| Административная панель | Контент, игровые серверы, пользователи, роли, модули и диагностика |
| Модули | Подключаемая функциональность, например ежедневные награды |
| Эксплуатация | Уведомления, аудит действий, диагностика и обновления |

Наличие конкретной функции зависит от **версии KaevCMS**, настроенного драйвера и возможностей игровой базы. Не все игровые сборки поддерживают одинаковый набор операций.

## С чего начать

1. Выберите тип размещения: [Ubuntu / VDS](/guide/vds) или [виртуальный хостинг](/guide/shared-hosting).
2. Проверьте системные требования и скачайте подходящий **полный** релиз.
3. Установите CMS и настройте отдельную базу данных.
4. Подключите игровые серверы через административную панель.
5. Проверьте почту, диагностику, безопасность и резервные копии.
