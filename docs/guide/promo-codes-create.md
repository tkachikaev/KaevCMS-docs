# Создание промокода

1. Откройте **Промокоды → Создать промокод**.
2. Введите код и выберите **игровой сервер**.
3. Добавьте награды: **ID предмета** и **количество**.
4. При необходимости укажите время действия и лимиты активации.
5. Сохраните промокод и убедитесь, что он включён.

Игрок вводит код в личном кабинете. При успешной активации предметы появятся в Веб-инвентаре выбранного сервера.

::: tip
Сначала проверьте новый код на тестовом аккаунте.
:::
