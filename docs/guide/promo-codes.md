# Промокоды

**Промокоды** — модуль подарков по специальному коду. Администратор создаёт промокод для игрового сервера, а игрок активирует его в личном кабинете и получает награду **в Веб-инвентарь**.

## Начало работы

1. Включите модуль **Промокоды** в разделе **«Модули»**.
2. Откройте раздел **«Промокоды»** в админке.
3. Создайте код, выберите сервер и награды.

**[Как создать промокод →](/guide/promo-codes-create)**

В разделе также доступны статистика и история активаций. Для передачи предметов персонажам используйте [очередь наград](/guide/reward-delivery).
