# Установка на виртуальном хостинге

Если нельзя направить домен непосредственно на каталог public внутри CMS, используется **разделённый пакет** (split layout). Он оставляет исходный код закрытым, а в публичный каталог кладёт только точку входа и статические файлы.

## Рекомендуемая структура

~~~text
site-root/
├── kaevcms-core/   ← закрытое ядро
└── public_html/     ← Document Root
    ├── index.php
    ├── install/
    └── uploads/
~~~

Название public_html зависит от хостера. Никогда не распаковывайте всё приложение внутрь публичного каталога.

## Подготовьте пакет

Для сборки из исходников на Windows предусмотрена команда:

~~~powershell
.\deployment\windows\build-shared-hosting-package.ps1
~~~

При нестандартном публичном каталоге укажите его точное имя:

~~~powershell
.\deployment\windows\build-shared-hosting-package.ps1 `
  -PublicDirectoryName example.hosting.test
~~~

Если в релизе уже есть подготовленный shared-hosting ZIP, используйте **именно его**. Скрипт выше нужен при самостоятельной сборке из исходников.

## Установка

1. Подготовьте пустую базу MySQL/MariaDB и отдельного пользователя.
2. Распакуйте split-архив **в родительский каталог сайта**, сохранив расположение приватного ядра рядом с публичным каталогом.
3. Убедитесь, что index.php находится непосредственно в Document Root.
4. Включите HTTPS и откройте /install/.
5. После завершения проверьте удаление /install/ и работоспособность сайта.

## Перед обновлением

Для виртуального хостинга у KaevCMS есть Web Update. Его применимость к вашей версии подтверждается **манифестом конкретного пакета** — не устанавливайте произвольный архив от другой ветки.
