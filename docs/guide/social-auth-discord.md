# Подключение Discord

<SocialProviderIcon name="discord" :size="48" />

Эти настройки администратор сайта выполняет один раз.

## Шаги подключения

1. Создайте приложение (**New Application**) на [Discord Developer Portal](https://discord.com/developers/applications).
2. В разделе **OAuth2 → Redirects** добавьте точный Callback URL из KaevCMS.
3. Скопируйте **Client ID** и **Client Secret**, сохраните настройки в KaevCMS и включите вход. **Создавать бота не нужно.**

::: tip Где взять Callback URL?
В **Админка → Настройки → Регистрация → Социальная авторизация → Discord** нажмите **«Копировать»** рядом с адресом возврата. Не изменяйте его. Для рабочего сайта нужен HTTPS. **Сохраните настройки и отдельно включите вход.**
:::

## Для игроков

После включения Discord появится среди разрешённых способов входа. Для уже существующего CMS-аккаунта сначала нужно войти обычным способом, затем открыть **ЛК → Безопасность** и привязать сервис. **По совпадающему email аккаунты не объединяются.**

::: warning
KaevCMS запрашивает только `identify` и `email`, без доступа к серверам Discord. Даже подтверждённый Discord email дополнительно проверяется письмом CMS при создании нового аккаунта.
:::

Если не получается войти, сверьте Client ID, секрет (если нужен), точный Callback URL и права приложения. Проверьте настройки отправки почты и разрешение регистрации на сайте.

[Кабинет разработчика Discord](https://discord.com/developers/applications) · [Все способы входа](/guide/social-auth).
