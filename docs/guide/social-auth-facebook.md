# Подключение Facebook

<SocialProviderIcon name="facebook" :size="48" />

Эти настройки администратор сайта выполняет один раз.

## Шаги подключения

1. Создайте приложение на [Meta for Developers](https://developers.facebook.com/apps/) и подключите **Facebook Login** для веб-сайта.
2. В поле **Valid OAuth Redirect URIs** укажите точный Callback URL из KaevCMS.
3. Внесите **App ID** как Client ID и **App Secret** как Client Secret в KaevCMS. Для публичного входа переведите приложение Meta в **Live** с доступным разрешением `email`; затем включите вход в KaevCMS.

::: tip Где взять Callback URL?
В **Админка → Настройки → Регистрация → Социальная авторизация → Facebook** нажмите **«Копировать»** рядом с адресом возврата. Не изменяйте его. Для рабочего сайта нужен HTTPS. **Сохраните настройки и отдельно включите вход.**
:::

## Для игроков

После включения Facebook появится среди разрешённых способов входа. Для уже существующего CMS-аккаунта сначала нужно войти обычным способом, затем открыть **ЛК → Безопасность** и привязать сервис. **По совпадающему email аккаунты не объединяются.**

::: warning
В режиме Development Meta обычно допускает только пользователей с ролями приложения. Facebook может не передавать email — в таком случае игрок укажет и подтвердит его письмом CMS.
:::

Если не получается войти, сверьте Client ID, секрет (если нужен), точный Callback URL и права приложения. Проверьте настройки отправки почты и разрешение регистрации на сайте.

[Кабинет разработчика Facebook](https://developers.facebook.com/apps/) · [Все способы входа](/guide/social-auth).
