# Подключение Google

<SocialProviderIcon name="google" :size="48" />

Эти настройки администратор сайта выполняет один раз.

## Шаги подключения

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/apis/credentials) и настройте экран согласия OAuth.
2. Создайте OAuth-клиент типа **Web application**. В **Authorized redirect URIs** вставьте точный адрес возврата из KaevCMS.
3. Перенесите **Client ID** и **Client Secret** в KaevCMS, сохраните и отдельно включите вход.

::: tip Где взять Callback URL?
В **Админка → Настройки → Регистрация → Социальная авторизация → Google** нажмите **«Копировать»** рядом с адресом возврата. Не изменяйте его. Для рабочего сайта нужен HTTPS. **Сохраните настройки и отдельно включите вход.**
:::

## Для игроков

После включения Google появится среди разрешённых способов входа. Для уже существующего CMS-аккаунта сначала нужно войти обычным способом, затем открыть **ЛК → Безопасность** и привязать сервис. **По совпадающему email аккаунты не объединяются.**

::: warning
Сервис запрашивает только `openid`, `email` и `profile`. Для внешних адресов (не Gmail/подходящий Google Workspace) CMS дополнительно проверит почту письмом. Если Google-приложение в тестовом режиме, добавьте тестировщиков.
:::

Если не получается войти, сверьте Client ID, секрет (если нужен), точный Callback URL и права приложения. Проверьте настройки отправки почты и разрешение регистрации на сайте.

[Кабинет разработчика Google](https://console.cloud.google.com/apis/credentials) · [Все способы входа](/guide/social-auth).
