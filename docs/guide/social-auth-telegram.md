# Подключение Telegram

<SocialProviderIcon name="telegram" :size="48" />

Игроки смогут входить на сайт через Telegram. Для настройки понадобится бот и реквизиты **Client ID / Client Secret**, которые выдаёт BotFather.

## 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду **`/newbot`**, задайте название и уникальное имя, заканчивающееся на `bot`. Если бот уже существует, используйте **`/mybots`**.
3. Откройте **мини-приложение BotFather** через **Open App / Открыть приложение** и выберите созданного бота.
4. Найдите **Login Widget / Web Login**. Это настройки нового входа Telegram через OIDC, **не** кнопка **Domain** в обычном чат-меню Bot Settings.

::: tip
Выданный при создании бота **HTTP API Token — не Client Secret** для входа на сайт. Не вставляйте его в настройки социальной авторизации KaevCMS и никому не показывайте.
:::

## 2. Разрешите адреса сайта

1. В админке KaevCMS откройте **Настройки → Регистрация → Социальная авторизация → Telegram → Настроить**.
2. Рядом с **«Адрес возврата (Callback URL)»** нажмите **«Копировать»**.
3. В мини-приложении BotFather откройте **Login Widget / Web Login** и добавьте в **Allowed URLs**:
   - **Адрес сайта:** `https://example.com`
   - **Адрес возврата:** `https://example.com/auth/social/telegram/callback`
4. Вместо примера используйте **свой домен и точный Callback URL из KaevCMS**. Выберите алгоритм **RS256** (обычно он уже установлен по умолчанию).

::: warning
Оба адреса должны быть разрешены в Telegram. Для рабочего сайта нужен корректный **HTTPS `APP_URL`**. Даже небольшое отличие Callback URL от адреса, зарегистрированного в BotFather, может помешать авторизации.
:::

## 3. Включите вход в KaevCMS

1. В том же разделе **Login Widget / Web Login** скопируйте **Client ID** и **Client Secret**.
2. Вставьте их в соответствующие поля Telegram в админке KaevCMS.
3. Нажмите **«Сохранить настройки провайдера»**.
4. Отдельно включите **«Разрешить вход»** у Telegram.
5. Выйдите из сайта и проверьте кнопку **«Войти через Telegram»** на странице авторизации.

**Готово:** если подключение выполнено правильно, Telegram подтвердит вход и вернёт игрока на сайт.

## Что происходит при первом входе?

Telegram не передаёт email в используемом KaevCMS OIDC-потоке. Поэтому новый игрок **указывает email, подтверждает его письмом KaevCMS и выбирает логин сайта**. Убедитесь, что [отправка почты](/guide/mail) работает.

Если игрок уже зарегистрирован, ему нужно **сначала войти обычным способом**, а затем открыть **ЛК → Безопасность** и привязать Telegram. **Совпадение email не объединяет аккаунты автоматически.**

## Если вход не работает

- Проверьте **Allowed URLs**, точный Callback URL, HTTPS и `APP_URL`.
- Убедитесь, что вводили именно **Client Secret от Login Widget**, а не токен Bot API.
- Проверьте, что Telegram включён в KaevCMS и выбран **RS256**.
- Если админка пишет об отсутствии **JWT/JWKS**, обновите KaevCMS до сборки, содержащей поддержку Telegram OIDC. В актуальной ветке **`Social-Auth`** зависимость **`firebase/php-jwt ^7.2`** уже добавлена; вручную обходить проверку не нужно.
- Для регистрации нового игрока нужны разрешённая регистрация и работающая почта.
