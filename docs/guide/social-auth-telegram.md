# Подключение Telegram

<SocialProviderIcon name="telegram" :size="48" />

Эти настройки администратор сайта выполняет один раз.

## Шаги подключения

1. Создайте бота через [@BotFather](https://t.me/BotFather) и откройте его **Login Widget**.
2. В **Allowed URLs** укажите адрес сайта `https://ваш-домен` и **полный Callback URL** из KaevCMS. Выберите алгоритм подписи **RS256**.
3. Перенесите выданные BotFather **Client ID** и **Client Secret** в KaevCMS и сохраните.

::: tip Где взять Callback URL?
В **Админка → Настройки → Регистрация → Социальная авторизация → Telegram** нажмите **«Копировать»** рядом с адресом возврата. Не изменяйте его. Для рабочего сайта нужен HTTPS. **Сохраните настройки и отдельно включите вход.**
:::

## Для игроков

После включения Telegram появится среди разрешённых способов входа. Для уже существующего CMS-аккаунта сначала нужно войти обычным способом, затем открыть **ЛК → Безопасность** и привязать сервис. **По совпадающему email аккаунты не объединяются.**

::: warning
**Ограничение текущей ветки `Social-Auth`: Telegram нельзя включить без утверждённой библиотеки проверки JWT/JWKS.** Одних настроек недостаточно. Telegram OIDC не сообщает email: игрок укажет его и подтвердит письмом CMS. Это новый вход через OIDC, а не старый iframe-виджет.
:::

Если не получается войти, сверьте Client ID, секрет (если нужен), точный Callback URL и права приложения. Проверьте настройки отправки почты и разрешение регистрации на сайте.
