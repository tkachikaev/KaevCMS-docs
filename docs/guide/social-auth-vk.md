# Подключение VK ID

<SocialProviderIcon name="vk" :size="48" />

Эти настройки администратор сайта выполняет один раз.

## Шаги подключения

1. Создайте веб-приложение на [новой платформе VK ID](https://id.vk.ru/) — не используйте старую систему VK OAuth.
2. Добавьте точный **Redirect URI** из KaevCMS и разрешение **`email`**.
3. Скопируйте **Application ID** в KaevCMS. **Client Secret не требуется**. Сохраните и включите вход.

::: tip Где взять Callback URL?
В **Админка → Настройки → Регистрация → Социальная авторизация → VK ID** нажмите **«Копировать»** рядом с адресом возврата. Не изменяйте его. Для рабочего сайта нужен HTTPS. **Сохраните настройки и отдельно включите вход.**
:::

## Для игроков

После включения VK ID появится среди разрешённых способов входа. Для уже существующего CMS-аккаунта сначала нужно войти обычным способом, затем открыть **ЛК → Безопасность** и привязать сервис. **По совпадающему email аккаунты не объединяются.**

::: warning
Перед регистрацией нового игрока CMS всегда подтверждает почту письмом. Интеграция использует новый VK ID с PKCE; приложение, требующее обязательный `service_token`, не подходит для этой стандартной настройки.
:::

Если не получается войти, сверьте Client ID, секрет (если нужен), точный Callback URL и права приложения. Проверьте настройки отправки почты и разрешение регистрации на сайте.
