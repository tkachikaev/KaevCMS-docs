# Подключение Яндекс ID

<SocialProviderIcon name="yandex" :size="48" />

Эти настройки администратор сайта выполняет один раз.

## Шаги подключения

1. Создайте приложение для авторизации пользователей на [Яндекс OAuth](https://oauth.yandex.ru/).
2. Зарегистрируйте точный **Redirect URI** из KaevCMS. Выберите права **`login:email`** и **`login:info`**.
3. Перенесите **Client ID** и **Client Secret** в KaevCMS, сохраните и включите вход.

::: tip Где взять Callback URL?
В **Админка → Настройки → Регистрация → Социальная авторизация → Яндекс ID** нажмите **«Копировать»** рядом с адресом возврата. Не изменяйте его. Для рабочего сайта нужен HTTPS. **Сохраните настройки и отдельно включите вход.**
:::

## Для игроков

После включения Яндекс ID появится среди разрешённых способов входа. Для уже существующего CMS-аккаунта сначала нужно войти обычным способом, затем открыть **ЛК → Безопасность** и привязать сервис. **По совпадающему email аккаунты не объединяются.**

::: warning
При первом входе новый игрок подтверждает email письмом из CMS, в том числе для адреса Яндекс.
:::

Если не получается войти, сверьте Client ID, секрет (если нужен), точный Callback URL и права приложения. Проверьте настройки отправки почты и разрешение регистрации на сайте.

[Кабинет разработчика Яндекс ID](https://oauth.yandex.ru/) · [Все способы входа](/guide/social-auth).
