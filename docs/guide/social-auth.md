# Социальная авторизация

Администратор KaevCMS сам выбирает, через какие сервисы игроки могут входить на сайт. Обычный вход по логину и паролю остаётся.

::: info Версия CMS
Функция реализована в ветке [Social-Auth](https://github.com/tkachikaev/KaevCMS/tree/Social-Auth). Если в установленной сборке нет раздела социальной авторизации, эта возможность в ней ещё недоступна.
:::

## Перед настройкой

1. Убедитесь, что для рабочего сайта установлен правильный **HTTPS-адрес `APP_URL`**.
2. [Настройте почту](/guide/mail) и проверьте отправку тестового письма — она нужна при регистрации через многие сервисы.
3. Откройте **Админка → Настройки → Регистрация → Социальная авторизация**.

## Как включить сервис

1. У нужного провайдера нажмите **«Настроить»** и затем **«Открыть консоль провайдера»**.
2. Создайте приложение на стороне сервиса. Скопируйте **«Адрес возврата (Callback URL)»** кнопкой **«Копировать»** из KaevCMS и укажите его в настройках приложения. Не составляйте адрес вручную.
3. Перенесите **Client ID / App ID** и, если нужен, **Client Secret**. Нажмите **«Сохранить настройки провайдера»**.
4. **Отдельно включите** переключатель **«Разрешить вход»** рядом с сервисом и проверьте вход тестовым пользователем.

::: tip
Сохранение реквизитов **само по себе не включает вход**. При смене Client ID сервис отключится до повторного включения. Секреты хранятся зашифрованными; пустое поле сохраняет ранее заданный секрет.
:::

## Вход и привязка аккаунтов

- **Новый игрок** выбирает включённый сервис при входе, при необходимости подтверждает email и задаёт логин сайта.
- **Существующий игрок** сначала входит обычным способом, затем открывает **ЛК → Безопасность**, выбирает **«Привязать»** и подтверждает личность.
- **Совпадение email никогда не связывает существующие аккаунты автоматически**. Один внешний аккаунт нельзя привязать к двум учётным записям CMS.
- Отключение сервиса скрывает его для входа, **но не удаляет привязку**. Сброс пароля CMS по email **отзывает прежние сеансы и удаляет все социальные привязки** — после восстановления их можно добавить заново.
- Социальный вход относится к **учётным записям сайта**, а не к административному входу или игровым аккаунтам Lineage II.

## Если не получается войти

Проверьте, что адрес возврата у провайдера полностью совпадает с адресом из CMS, сайт работает по HTTPS, а сервис включён. Для новой регистрации нужна разрешённая регистрация на сайте и работающая почта. Если email уже используется, войдите в существующую учётную запись или восстановите пароль и затем привяжите сервис в ЛК.
