# Работа с обращениями

Игрок создаёт обращение из **личного кабинета → Техническая поддержка**.

## Как ответить

1. В админке откройте **Техническая поддержка → Обращения**.
2. Выберите нужный тикет и прочитайте переписку.
3. При необходимости назначьте **ответственного сотрудника**.
4. Напишите ответ игроку или добавьте **внутреннюю заметку**, которую игрок не увидит.
5. Измените статус или закройте обращение.

Право редактора отвечать и добавлять заметки настраивается отдельно. Аудитор может только просматривать обращения.
