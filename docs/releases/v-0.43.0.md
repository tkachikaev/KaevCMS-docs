# KaevCMS 0.43.0

**Опубликовано:** 2026-07-28 · **Тип:** Предварительная версия

[Оригинал на GitHub ↗](https://github.com/tkachikaev/KaevCMS/releases/tag/0.43.0)

## Что нового

## KaevCMS 0.43.0 — первый публичный релиз

KaevCMS — открытая CMS на Laravel для серверов Lineage II.

Она включает публичный сайт, личный кабинет игрока, административную панель, подключение LoginServer и GameServer, статистику сервера, веб-инвентарь наград, промокоды, ежедневные награды, темы оформления, локализацию и систему обновлений.

### Что изменилось в 0.43.0

Версия 0.43.0 открывает новую публичную релизную линию KaevCMS.

* удалена устаревшая дорелизная документация;
* очищен состав production-сборки;
* удалены старые audit-файлы;
* версия 0.42.4 установлена как новая база кумулятивных обновлений;
* исправлена Windows-регрессия в проверках cumulative update workflow;
* добавлены контракты удаления устаревших файлов при обновлении.

Схема базы данных CMS, игровые драйверы, встроенные модули, темы и пользовательские runtime-файлы не изменялись.

### Какой архив скачать

#### `KaevCMS-0.43.0-full.zip`

Стандартная полная сборка.

Подходит для:

* VDS или выделенного сервера;
* локальной установки;
* хостинга, где Document Root можно направить на каталог `public`;
* разработки и самостоятельной сборки проекта.

Архив не содержит готовый каталог `vendor`. PHP-зависимости устанавливаются через Composer.

#### `KaevCMS-0.43.0-shared-hosting.zip`

Готовая production-сборка для shared-hosting.

Используйте её, если хостинг не позволяет направить домен непосредственно на каталог `public`.

Сборка уже разделена на:

* закрытое ядро `kaevcms-core`;
* публичный каталог `public_html`;
* production-зависимости Composer без development-пакетов.

Каталоги можно переименовать под структуру конкретного хостинга. Например, вместо `public_html` может использоваться каталог с именем домена.

### Требования

* PHP 8.3 или новее;
* MySQL или MariaDB;
* PDO и `pdo_mysql`;
* mbstring;
* fileinfo;
* DOM;
* OpenSSL;
* tokenizer;
* ctype;
* JSON;
* session;
* HTTPS для рабочего сайта.

### Установка

1. Распакуйте подходящий архив.
2. Направьте домен на публичный каталог.
3. Откройте в браузере:

```text
https://ваш-домен/install/
```

4. Выполните шаги Web Installer.
5. После успешной установки удалите публичный каталог `/install`.

Не размещайте `.env`, код приложения, журналы, резервные копии и закрытое ядро внутри доступного из интернета каталога.

Не назначайте права `777` всему проекту.

### Основные возможности

* публичный сайт и личный кабинет игрока;
* административная панель;
* русская и английская локализация;
* роли владельца, администратора и редактора;
* двухфакторная аутентификация;
* подключение LoginServer и GameServer;
* поддержка L2JMobius через профили схем базы данных;
* диагностика подключений и структуры внешних баз;
* создание игровых аккаунтов;
* изменение игровых паролей;
* статистика персонажей, кланов, героев и замков;
* веб-инвентарь наград;
* универсальная очередь `kaev_reward_queue`;
* встроенные модули Promo Codes и Daily Rewards;
* публичные темы и отдельные темы личного кабинета;
* каталог игровых предметов и пользовательские иконки;
* Web Updater для shared-hosting;
* CLI Updater для VDS;
* резервные копии и восстановление при обновлении.

### Обновление

Для обновления KaevCMS 0.42.4 до версии 0.43.0 используйте:

```text
KaevCMS-cumulative-update-0.42.4-to-0.43.0.zip
```

На shared-hosting пакет загружается через Web Updater в административной панели.

Файлы в `public/uploads`, настройки `.env`, рабочая база CMS, журналы и другие runtime-данные при обновлении не заменяются.
