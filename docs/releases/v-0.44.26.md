# KaevCMS 0.44.26

**Опубликовано:** 2026-07-30 · **Тип:** Предварительная версия

[Оригинал на GitHub ↗](https://github.com/tkachikaev/KaevCMS/releases/tag/0.44.26)

## Что нового

## Изменения с версии 0.43.0 до 0.44.26

- Добавлена полноценная поддержка сборок L2JMobius через единый драйвер.
- Появился модуль **«Техническая поддержка»**: тикеты, переписка, статусы, категории, внутренние заметки, ответственные и автоматическая очистка.
- Старый редактор новостей и страниц заменён на **Tiptap**: таблицы, изображения, ссылки, списки, выравнивание, размеры текста и расширенная палитра.
- Улучшены интерфейс админки, личный кабинет, фильтры, адаптивность и иконки модулей.
- Усилены безопасность, Livewire-авторизация, установка, обновления и тестирование.
- Исправлена проблема с файловым кэшем, которая в некоторых случаях приводила к ошибке HTTP 500.
- Исправлено множество ошибок и повышена общая стабильность.

### Полная сборка для VDS

`KaevCMS-0.44.26-full.zip`

Используется для чистой установки KaevCMS на VDS.

### Сборка для виртуального хостинга

`KaevCMS-0.44.26-shared-hosting.zip`

Используется для чистой установки KaevCMS на виртуальный хостинг.

### Кумулятивное обновление до 0.44.26

Для установок версий от **0.42.4** до **0.44.25**:

`KaevCMS-cumulative-update-0.42.4-0.44.25-to-0.44.26.zip`

- На VDS кумулятивное обновление устанавливается из консоли сервера.
- На виртуальном хостинге кумулятивное обновление устанавливается через раздел обновления в настройках административной панели.
