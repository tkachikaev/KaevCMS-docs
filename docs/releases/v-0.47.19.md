# KaevCMS 0.47.19

**Опубликовано:** 2026-08-02 · **Тип:** Предварительная версия

[Оригинал на GitHub ↗](https://github.com/tkachikaev/KaevCMS/releases/tag/0.47.19)

## Что нового

## Добавлено

- Обновление CMS через административную панель на VDS.
- Безопасный локальный VDS update-agent без открытых сетевых портов.
- Поддержка проектов, установленных под root или обычным системным пользователем.
- Окно состояния обновления с автоматическим отслеживанием процесса.
- Центр уведомлений администратора.
- Настройки источников и срока хранения уведомлений.
- Безопасный диагностический архив для обращения в поддержку.
- Новая статистика диска, базы данных, игроков, аккаунтов, персонажей и обращений.
- Архив промокодов с возможностью восстановления.
- Полное удаление неиспользованных промокодов.
- Удаление закрытых обращений технической поддержки владельцем проекта.
- Общие компоненты полей, кнопок, вкладок, фильтров и карточек админки.

## Изменено

- Улучшена страница системной информации.
- Улучшены интерфейс и журнал обновления CMS.
- Переработано мобильное меню админки и личного кабинета.
- Добавлена защита от повторного запуска обновления.
- Технические сообщения Web Inventory заменены понятными сообщениями для игроков.
- Статус передачи награды теперь отображается как «Передано».
- Поля и фильтры Support Tickets приведены к общему дизайну админки.
- Улучшены права Owner, Administrator, Editor и Auditor.
- Installer автоматически удаляется после успешной установки.

## Исправлено

- Ложные ошибки `429 Too Many Requests` при обновлении CMS.
- Ошибка 429 при проверке асинхронного режима почты.
- Проблемы с правами файлов после обновления на VDS.
- Обновление проектов, установленных под root.
- Выборочные ошибки HTTP 500 после Web Update.
- Работа VDS update-agent с разными конфигурациями PHP-FPM.
- Отображение внутренних названий таблиц и полей игрокам.
- Проверка выбранного персонажа и наград в Web Inventory.
- Повторяющиеся уведомления и диагностические сообщения.
- Горизонтальная прокрутка и переполнение на мобильных устройствах.
- Надёжность обновления и миграций встроенных модулей.
- Стабильность релизных архивов, метаданных и автоматических тестов.
